# Start the emulator

Run **Sardina: Start Emulator** to boot the SFOS emulator for your
selected build target, so you have somewhere to deploy and run your app
without a physical device.

The Devices view in the SFOS activity bar shows the emulator's status
once it starts. See
[docs.sailfishos.org](https://docs.sailfishos.org/Tools/Sailfish_SDK/)
for emulator setup details.

If the emulator image isn't installed yet, use
**Sardina: Install Available Emulator** first.
