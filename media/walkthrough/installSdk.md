# Install and detect the Sailfish SDK

Install the Sailfish SDK from [docs.sailfishos.org](https://docs.sailfishos.org/Develop/SDK/Installation/)
if you haven't already.

Once it's installed, this extension looks for it in the usual locations
automatically. If it isn't found, run **Sailfish: Set SDK Path** to point it
at your SDK installation directory directly.

You'll know it worked once the SDK is detected and its version appears in the
Sailfish OS output channel.
