# Build, deploy and run

Run **Sardina: Build, Deploy and Run** to build your app for the selected
target, install it on your selected device or emulator, and launch it — all
in one step.

You can also run each stage on its own with **Sardina: Build**,
**Sardina: Deploy** and **Sardina: Run**, which is useful while iterating on
just one part of the cycle.

See [docs.sailfishos.org](https://docs.sailfishos.org/Tools/Sailfish_SDK/Deploying_packages/)
for details on how Sailfish OS builds and packages applications.
