# Create a project

Run **Sailfish: New Project** to scaffold a new Sailfish OS application from a
template, or open an existing one that already has an `rpm/*.spec` file.

See [docs.sailfishos.org](https://docs.sailfishos.org/Develop/Apps/) for an
overview of Sailfish OS application structure and packaging.

Once a Sailfish project is open in your workspace, the rest of this
walkthrough's commands become available for it.
