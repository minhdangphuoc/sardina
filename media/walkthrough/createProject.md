# Create a project

Run **Sardina: New Project** to scaffold a new SFOS application from a
template, or open an existing one that already has an `rpm/*.spec` file.

See [docs.sailfishos.org](https://docs.sailfishos.org/Develop/Apps/) for an
overview of SFOS application structure and packaging.

Once an SFOS project is open in your workspace, the rest of this
walkthrough's commands become available for it.
